Aito Nurmi Integrations

Aito Nurmi Integrations is the OAuth application used for the owner's Google integrations. This page covers its Google Search Console and Google Tag Manager connections, the earlier local Drive read pilot, a separately enabled owner-only Drive tool and planned owner-only Gmail, Calendar and Tasks connections.

Purpose and users

The application is a local integration used by the owner and an authorized operator. It reads search performance data from approved Search Console properties and account and container information from Tag Manager for reporting and technical checks.

Kauneushoitola Hanna (KHH) is the first reference use case. KHH is a user of the integration, not its permanent application name.

The application does not provide public registration. The Google account user authorizes access through Google's consent screen. Ownership of Google resources does not transfer to the integration.

Google permissions

  • Search Console: https://www.googleapis.com/auth/webmasters.readonly
  • Tag Manager: https://www.googleapis.com/auth/tagmanager.readonly

These Search Console and Tag Manager permissions remain read-only. They do not permit editing or publishing Tag Manager configurations. The separate Drive and planned personal-service uses are described below; this description does not cover GA4, Google Ads or other integrations. A broader application name does not enable additional integrations or permissions.

Earlier local-only Drive read pilot

The earlier local-only read pilot completed an owner-selected operational read test using https://www.googleapis.com/auth/drive.readonly. That permission does not grant write, delete or sharing rights. The pilot returned only pass/fail results to the assistant, not file names or contents. Its narrow local-only handling is historical and does not authorize the separate tool below.

Optional owner-only, on-demand Drive tools

When enabled by separate Google consent and operational checks, this tool uses https://www.googleapis.com/auth/drive. This permission covers all files accessible to the account, not just a selected folder. The tool is for the owner's assistant, not public registration or other assistant profiles.

Allowed operations are narrower than the Google permission: find and inspect metadata, download selected files to private local copies, create folders, create or edit supported files, rename or move one file, and create named copies as checkpoints. Initial editing supports UTF-8 text files and Google Docs text, with a 1 MiB input limit. Sheets/Slides content editing, folder moves and shared-drive moves are not supported in this initial tool. Metadata search coverage and revision availability must be reported honestly.

Checkpoint copies have their own file IDs and are separate from Google's automatically managed revision history; they are not named native revisions or a promise of permanent history. The scope can technically permit deletion and sharing, but deletion, trashing, sharing and ownership changes are not supported tool operations. A move can change inherited access through the destination folder and requires explicit acknowledgment.

Only information needed for an individually requested task may be supplied to the owner's Hermes conversation and its OpenAI model service, under the separate processing conditions in the Privacy Policy. There is no automated whole-Drive scan. Publication does not activate the tool, grant Google permissions, verify provider settings or certify compliance. The operator must verify secure storage and the permitted data path before consent and use.

Planned owner-only Gmail, Calendar and Tasks connections

When separately enabled by the owner's Google consent and operational checks, these connections are for the owner's personal assistant and an individually requested task, not public registration, other assistant profiles or background monitoring. Keep is excluded.

  • Gmail: https://www.googleapis.com/auth/gmail.readonly for requested mailbox search and message reading. This is mailbox-wide access, not a message-only grant. The separate Gmail credential must grant only this permission; sending, modifying, labelling, archiving and deleting email are not authorized.
  • Calendar: https://www.googleapis.com/auth/calendar.events for reading, creating and editing accessible events, plus https://www.googleapis.com/auth/calendar.calendarlist.readonly to select calendars. This does not authorize calendar creation, sharing or access-control administration.
  • Tasks: https://www.googleapis.com/auth/tasks for reading, creating and editing Google Tasks.

The Calendar and Tasks permissions technically permit event and task deletion, but the approved operations do not authorize deletion, clearing lists, bulk changes or unsolicited invitations and notifications. Each actual creation or edit requires a specific owner request and target; granting a permission is not a request to change existing data.

Only information necessary for an individually requested task may be supplied to the owner's Hermes conversation and its OpenAI model service, subject to the Privacy Policy and a check of provider data-use suitability. There is no approval to scan the mailbox, calendars or tasks automatically or to send their data to other recipients.

Publication does not activate these connections or prove that creation and editing tools are implemented or live-tested. Exact account and granted scopes, secure credential storage, persistence, refresh and the intended consumer must be checked before use. Gmail and the Calendar/Tasks credential must remain separate from each other and from Drive; clients within one Google application do not provide independent app-level revocation.

Managing authorization

You can revoke authorization in your Google account's connections settings. Continued access depends on valid authorization and Google's conditions. This page does not guarantee an uninterrupted connection.

Publishing these documents or changing the application's name does not demonstrate Google OAuth Production status, Google verification or production readiness.
