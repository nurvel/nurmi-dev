Aito Nurmi Integrations

Aito Nurmi Integrations is the OAuth application used for the owner's Google integrations. This page covers its current Google Search Console and Google Tag Manager connections and the owner's separately approved preparation of a local Drive read pilot.

Purpose and users

The application is a local integration used by the owner and an authorized operator. It reads search performance data from approved Search Console properties and account and container information from Tag Manager for reporting and technical checks.

Kauneushoitola Hanna (KHH) is the first reference use case. KHH is a user of the integration, not its permanent application name.

The application does not provide public registration. The Google account user authorizes access through Google's consent screen. Ownership of Google resources does not transfer to the integration.

Google permissions

  • Search Console: https://www.googleapis.com/auth/webmasters.readonly
  • Tag Manager: https://www.googleapis.com/auth/tagmanager.readonly

These are read-only permissions. They do not permit editing or publishing Tag Manager configurations. Apart from the planned Drive pilot below, this description does not cover GA4, Google Ads, Gmail or other services or providers. A broader application name does not enable additional integrations or permissions.

Planned owner-only local Drive read pilot

The owner has approved preparation of a local Drive read pilot for the owner's assistant only. The pilot is not activated. It is not available for public registration or other assistant profiles.

The proposed permission is https://www.googleapis.com/auth/drive.readonly. It would cover all files accessible to the account, not just a selected folder. It does not grant write, delete or sharing rights. The first test is further limited to one harmless file selected by the owner; that operational limit is not a narrower Google permission.

Before activation, the operator must verify secure credential storage and the permitted data path. The owner must then select the intended Google account, complete Google's consent and choose the test file. Publishing this description does not complete any of those steps, enable a Drive connection or authorize a Gmail connection, backup job or change to the existing integrations.

The planned pilot permits a local read test, not general cloud-model analysis of Drive files. Its data-handling conditions are described in the Privacy Policy below.

Managing authorization

You can revoke authorization in your Google account's connections settings. Continued access depends on valid authorization and Google's conditions. This page does not guarantee an uninterrupted connection.

Publishing these documents or changing the application's name does not demonstrate Google OAuth Production status, Google verification or production readiness.
