Aito Nurmi Integrations

Aito Nurmi Integrations is the OAuth application used for the owner's Google integrations. This page covers its currently approved Google Search Console and Google Tag Manager connections.

Purpose and users

The application is a local integration used by the owner and an authorized operator. It reads search performance data from approved Search Console properties and account and container information from Tag Manager for reporting and technical checks.

Kauneushoitola Hanna (KHH) is the first reference use case. KHH is a user of the integration, not its permanent application name.

The application does not provide public registration. The Google account user authorizes access through Google's consent screen. Ownership of Google resources does not transfer to the integration.

Google permissions

  • Search Console: https://www.googleapis.com/auth/webmasters.readonly
  • Tag Manager: https://www.googleapis.com/auth/tagmanager.readonly

These are read-only permissions. They do not permit editing or publishing Tag Manager configurations. This description does not cover GA4, Google Ads, Gmail, Drive or other services or providers. A broader application name does not enable additional integrations or permissions.

Managing authorization

You can revoke authorization in your Google account's connections settings. Continued access depends on valid authorization and Google's conditions. This page does not guarantee an uninterrupted connection.

Publishing these documents or changing the application's name does not demonstrate Google OAuth Production status, Google verification or production readiness.
