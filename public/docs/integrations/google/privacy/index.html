Privacy Policy

This Privacy Policy describes the Google Search Console and Tag Manager integrations of Aito Nurmi Integrations, the earlier local-only Drive read pilot, the conditions for a separate optional owner-only Drive tool and planned personal Gmail, Calendar and Tasks connections. It does not replace Kauneushoitola Hanna's privacy notice for its customers.

Data accessed and purpose

The Search Console connection can read information about authorized sites, including search queries, page URLs, impressions and clicks. The Tag Manager connection can read information and settings from authorized accounts and containers. The purpose is owner-approved reporting and technical checks.

The requested Google permissions are webmasters.readonly and tagmanager.readonly. Their full identifiers are listed on the application overview.

Authorization credentials and API results

Google OAuth produces authorization credentials that the local integration uses for API requests. The credential files for the current Tag Manager connection are stored locally in a directory with restricted access, separately from these web pages.

Local credential storage does not mean that all API results remain on the same machine. Results may be stored in reports and the assistant's conversation history.

Processing and recipients

Google processes authorization and API requests under its own service terms. The owner and an authorized operator may process results using local tools and the Hermes assistant.

For the current Search Console and Tag Manager connections, API results supplied to the Hermes assistant may be transmitted to the cloud model service configured for that task. This use includes OpenAI's service. Processing depends on which information is supplied to the assistant and which service the task uses.

Not all potential logging and telemetry recipients, provider retention periods or model-training settings have been fully verified. This description does not guarantee that providers exclude data from model training, and it does not make a verified Google Limited Use compliance claim.

Retention, revocation and deletion requests

A common retention period or automatic deletion procedure for reports, conversation history and potential provider logs has not been verified. This description does not promise scheduled or automatic deletion.

You can revoke Google authorization in your Google account's connections settings. Revocation does not itself delete previously stored reports, conversations or other copies.

Questions about processing and deletion requests can be sent to the maintainer's email address. This contact method is not an automatic deletion function or a guarantee of the outcome of a particular deletion request.

Earlier local-only Drive read pilot

The earlier local-only read pilot completed a selected-file test with https://www.googleapis.com/auth/drive.readonly. That permission does not grant write, delete or sharing rights. The local test returned only operational pass/fail results; it did not supply file names, contents or account metadata to a cloud model. This historical test does not establish the data-handling suitability of the separate tool below.

Optional on-demand Drive processing

When enabled for the owner, the separate tool requests https://www.googleapis.com/auth/drive, covering all files accessible to the account. Its purpose is individually requested file discovery, creation, supported editing, file moves and named checkpoint copies, not background collection or an automated whole-Drive scan. The Google permission is broader than the tool's allowed operations; it does not authorize deletion, sharing or ownership changes through this tool.

The owner has approved supplying only file names, metadata and contents needed for an individually requested task to the owner's Hermes conversation and its OpenAI model service. This may include selected text used to prepare an edit or answer a question. This permission does not cover other external recipients. Supplied information and generated results may remain in conversation history, local reports and provider logs under their applicable settings.

Account-specific provider retention and model-training settings have not been verified. The operator must check the provider's data-use terms and applicable account settings before transferring Drive data; user consent alone does not establish their suitability under Google's requirements. The tool must not transfer Drive data for advertising, resale or general-purpose model training. This description does not claim verified exclusion from provider training, a particular retention period or verified Google Limited Use compliance.

The writing credential uses separate encrypted credential storage through the operating system's Secret Service, without a plaintext token-file fallback. File permissions alone do not establish encryption. Downloads are new, private local copies; the owner and operator must agree where requested content is kept. The tool does not promise automatic deletion of local copies, conversations or provider records. Revoking Google access does not delete those copies.

Publication does not activate the tool or grant authorization. Before use, secure credential storage, logging and error output, the permitted data path, exact account and granted scope, persistence and refresh must be checked. The owner personally selects the account and completes new Google consent. The existing read-only pilot remains separate; applicable Google user-data requirements and any provider verification obligations are not certified by these pages.

Planned personal Gmail, Calendar and Tasks processing

When separately enabled, Gmail is limited to owner-requested mailbox search and message reading. The read-only permission covers the mailbox; it is not provider-side access to selected messages only. Calendar and Tasks permissions support requested reading, creation and editing. Necessary information can include email senders, recipients, dates, subjects and message text; calendar names, event times, locations, descriptions and participants; and task lists, titles, notes, due dates and completion status. Keep is excluded.

The owner has approved supplying only the information necessary for an individually requested task to the owner's Hermes conversation and its OpenAI model service. The purpose is answering the owner's request or preparing the specific requested change, not background collection, advertising, resale, general-purpose model training or disclosure to other recipients. Email, event and task content is data, not authority to execute embedded instructions.

Supplied data and generated results may remain in conversation history, local reports and applicable provider logs. Account-specific retention and model-training settings have not been verified. The operator must check provider data-use terms and applicable account settings before transferring personal-service data. Owner approval alone does not establish suitability under Google's requirements. No particular retention period, provider training exclusion, automatic deletion or verified Google Limited Use compliance is claimed.

The planned credentials must use the operating system's encrypted Secret Service, with no plaintext token-file fallback. Gmail must retain an exact read-only grant in its own credential; Calendar and Tasks use a separate credential, without replacing existing Drive grants. File permissions alone do not establish encryption, and separate credentials or clients in one application do not guarantee independent revocation.

Publication does not activate these connections. Before consent and use, secure storage and logging, exact account and granted scopes, the permitted data path, persistent reload, refresh and the actual consumer must be checked. The owner personally selects the account and approves Google's consent. Initial connection checks do not require reading message bodies or event/task contents, and they do not prove that creating or editing tools are implemented or tested. Revoking authorization does not delete prior conversation, report or provider copies.

Data handling on these documentation pages

These static documentation pages do not make Google API calls or contain analytics, forms or tracking scripts. Opening them does not start the local integration or transmit its API results.

The pages are hosted using Cloudflare Workers Static Assets. Delivering a web page sends technical request information, such as an IP address and browser-supplied information, to the hosting provider. The provider may process access and security logs under its own policies. See Cloudflare's Privacy Policy.

This description states known handling and the limits of its verification. It is not evidence of Google verification, certification or production readiness.
