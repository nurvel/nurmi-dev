Privacy Policy

This Privacy Policy describes the Google Search Console and Tag Manager integrations of Aito Nurmi Integrations. It does not replace Kauneushoitola Hanna's privacy notice for its customers.

Maintainer and contact

Veli-Pekka Nurmi
nurmi.vp@gmail.com

Data accessed and purpose

The Search Console connection can read information about authorized sites, including search queries, page URLs, impressions and clicks. The Tag Manager connection can read information and settings from authorized accounts and containers. The purpose is owner-approved reporting and technical checks.

The requested Google permissions are webmasters.readonly and tagmanager.readonly. Their full identifiers are listed on the application overview.

Authorization credentials and API results

Google OAuth produces authorization credentials that the local integration uses for API requests. The credential files for the current Tag Manager connection are stored locally in a directory with restricted access, separately from these web pages.

Local credential storage does not mean that all API results remain on the same machine. Results may be stored in reports and the assistant's conversation history.

Processing and recipients

Google processes authorization and API requests under its own service terms. The owner and an authorized operator may process results using local tools and the Hermes assistant.

API results supplied to the Hermes assistant may be transmitted to the cloud model service configured for that task. This use includes OpenAI's service. Processing depends on which information is supplied to the assistant and which service the task uses.

Not all potential logging and telemetry recipients, provider retention periods or model-training settings have been fully verified. This description does not guarantee that providers exclude data from model training, and it does not make a verified Google Limited Use compliance claim.

Retention, revocation and deletion requests

A common retention period or automatic deletion procedure for reports, conversation history and potential provider logs has not been verified. This description does not promise scheduled or automatic deletion.

You can revoke Google authorization in your Google account's connections settings. Revocation does not itself delete previously stored reports, conversations or other copies.

Questions about processing and deletion requests can be sent to the maintainer's email address. This contact method is not an automatic deletion function or a guarantee of the outcome of a particular deletion request.

Data handling on these documentation pages

These static documentation pages do not make Google API calls or contain analytics, forms or tracking scripts. Opening them does not start the local integration or transmit its API results.

The pages are hosted using Cloudflare Workers Static Assets. Delivering a web page sends technical request information, such as an IP address and browser-supplied information, to the hosting provider. The provider may process access and security logs under its own policies. See Cloudflare's Privacy Policy.

This description states known handling and the limits of its verification. It is not evidence of Google verification, certification or production readiness.
